# Triage labels

| Skill role        | GitHub label      | Meaning                                   |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | Awaiting maintainer evaluation            |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent          |
| `ready-for-human` | `ready-for-human` | Requires human implementation             |
| `wontfix`         | `wontfix`         | Will not be worked on                     |
